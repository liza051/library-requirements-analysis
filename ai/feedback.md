
# AI Feedback and Review

## Prompt Reference
AI Prompt 01 — Requirements Analysis

## Top 3 AI Mistakes Identified

### 1. Incorrect Use Case Relationship
**AI issue:** The initial diagram connected "Reserve a Book Copy" and "View Book Copy Availability" using an unnecessary include relationship.

**Student feedback:** These are separate Reader goals. The relationship was removed from the diagram.

**Related artifact:** use-cases/use-case-diagram.mmd

### 2. Unclear Actor Responsibilities
**AI issue:** The initial use case diagram did not clearly distinguish between a Reader requesting a loan or return and a Librarian registering the transaction.

**Student feedback:** Reader actions were renamed to "Request to Borrow a Book" and "Request to Return a Book". Librarian responsibilities were clarified.

**Related artifacts:** spec.md, use-cases/use-case-diagram.mmd

### 3. Diagram Format Limitation
**AI issue:** The Mermaid flowchart represented use cases visually but did not use standard UML Use Case notation.

**Student feedback:** This limitation was identified and documented. The diagram format should be checked against the instructor's expectations.

**Related artifact:** use-cases/use-case-diagram.mmd

## Final Student Evaluation

AI suggestions were treated as recommendations, not as final decisions. The student reviewed the proposed changes, corrected inconsistencies, and approved the final requirements.
