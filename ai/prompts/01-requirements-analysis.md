
# AI Prompt 01 — Requirements Analysis

## Goal
Analyze the requirements for the Library Reservation System and identify missing details, ambiguities, and possible inconsistencies.

## Prompt
Review the requirements for a Library Reservation System.

The system includes Readers, Librarians, Books, physical BookCopies, Reservations, and Loans.

The main use case selected for detailed analysis is "Reserve a Book Copy".

Identify:
- Possible actors and their goals.
- Alternative and error scenarios for the selected use case.
- Ambiguities in reservation rules.
- Possible inconsistencies with the existing Lab 1 data model.

Do not make final decisions on behalf of the student. Explain the reasoning behind each suggestion.

## Student's Role
The student reviews AI suggestions, decides which ones are relevant, and approves the final requirements and modeling decisions.
