
# AI Response 01 — Requirements Analysis

## Summary of AI Suggestions

AI suggested the following points for the Library Reservation System:

1. Identify Reader and Librarian as the main actors.
2. Select "Reserve a Book Copy" as the main use case for detailed analysis.
3. Include successful reservation and alternative scenarios for unavailable copies.
4. Link each reservation to a specific physical BookCopy.
5. Clarify the responsibilities of Readers and Librarians.

## Student Review and Feedback

The student reviewed the suggestions and accepted the relevant recommendations.

The following decisions were made:

- Keep one Author for each Book, consistent with Lab 1.
- Keep reservations linked to physical BookCopies.
- Separate the Reader's request to borrow or return a book from the Librarian's responsibility to register the transaction.
- Keep three reservation scenarios: successful reservation, no available copies, and an already reserved copy.

## Limitations Identified

- The initial use case diagram included an unnecessary relationship between viewing availability and reserving a copy.
- The initial actor responsibilities did not clearly distinguish requests from transaction registration.
- A Mermaid flowchart is not a formal UML Use Case diagram, so its suitability should be confirmed against the instructor's diagram requirements.

## Final Decision

The student reviewed and corrected the proposed model instead of accepting all AI suggestions automatically.
